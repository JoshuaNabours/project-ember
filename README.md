# project-ember

Project Ember is a local-first AI companion framework focused on real-time voice interaction, modular architecture, and privacy-conscious design.

Built using locally hosted language models through Ollama and Mistral 7B, the project explores how emotionally responsive AI systems can operate without heavy reliance on cloud infrastructure or subscription-based services.

The system combines:

* Python orchestration
* Local LLM inference
* Speech-to-text pipelines
* Text-to-speech synthesis
* OBS integration
* Vtuber/avatar interaction systems
* Real-time behavioral response layers

## Goals

* Build a scalable local AI interaction platform
* Explore real-time conversational systems
* Reduce operational cost through local inference
* Maintain user privacy by avoiding unnecessary cloud dependency
* Learn modern AI systems engineering through hands-on development

## Core Stack

Mistral 7B → Ollama → Python → STT/TTS Pipeline → OBS → Avatar Interface → User Interaction

## Current Areas of Development

* Voice Activity Detection (VAD)
* Realtime speech pipelines
* Emotion/reactive behavior systems
* OBS scene automation
* Modular memory systems
* AI-driven avatar interaction
